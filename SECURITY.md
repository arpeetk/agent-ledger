# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in `agent-ledger`, please report it responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, email: **security@example.com** (replace with your actual security contact).

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will acknowledge receipt within 48 hours and aim to provide a fix within 7 days for critical issues.

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Scope

This policy covers the `agent-ledger` codebase. The mock connectors are not intended for production use and should not be considered part of the security boundary.
